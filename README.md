# Gourd Guard

A custom Minecraft 1.21 Fabric minigame project with custom UI HUD, shaders, sounds, and datapack mechanics.

## Repository Structure
- datapack/: Datapack functions, tick loops, state machines, and game logic (data/gourd_guard/).
